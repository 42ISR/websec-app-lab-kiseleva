# app2.miorii.kitek-pg.ru

# Лабораторная работа: приложение

## Цель

Развернуть приложение из [списка](https://github.com/awesome-selfhosted/awesome-selfhosted?tab=readme-ov-file#password-managers) на поддомене

```text
app2.miorii.kitek-pg.ru
```

и настроить для него HTTPS с сертификатом от Let's Encrypt.

Постарайтесь выбрать приложение, которое имеет смысл на маленькой ВПСке (не сильно ресурсно затратное)

_Можете выбрать что-то угодно не из списка, что можно развернуть на 443 порту через Docker и накинуть сертификат_

_Если не уверены в актуальности и возможности деплоя - лучше уточните у меня_

## Перед началом

Проверьте, что есть DNS правило и адрес указывает на вашу VPS через

```bash
dig +short app2.%ваш_сабдомен%.kitek-pg.ru
```

Если команда ничего не вернула - сообщите

## Сдача

Проверьте работоспобность, если для доступа нужны креды - создайте тестовый аккаунт и закиньте мне в телеграм. Затем замените сверху URL на ветке `wip` и отправьте пул реквест.
